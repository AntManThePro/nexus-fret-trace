The Built-In TEST

The app plays 8 clean test tones through its own capture path — no file, no download, no guitar. This proves the whole chain (capture → timeline → tab) works in Safari.

The B/S TEST — Bends & Slides

★ This is the one still waiting on its first iPhone run — your run is the real verdict.

Also built into the app, no guitar needed. It plays a held note, a smooth slide, and a bend, and the app has to tell the difference between a slide, a bend, and two separate notes.

A2 held→slide up to D3→D3 held→bend +3, back to D3

Steps

Expected result ✎

  • Tab shows A2, then D3 marked with an s (slide)
  • A Bends: line under the tab reads D3 +3
  • The slide does not explode into a string of separate notes — it collapses to just A2 + D3

3

Real Guitar — Mic Test

The big one: the only test that proves a real guitar, in a real room, through the iPhone mic.

Clean test tones are easy mode. Strings have harmonics, fingers make noise, rooms echo. Play a clear single-note line — Fret Trace is monophonic, so one note at a time is exactly what it wants.

Steps

Expected result ✎

  • The tab matches the line you played — right notes, right order
  • No phantom notes from string noise, and no dropped notes on the quiet ones
  • A slide shows the destination note marked s; a bend that returns home gets a b and a Bends line entry
  • Honest limit: it won't catch chords or two notes at once — that's not built yet, not a failure of this test
Verdict:
